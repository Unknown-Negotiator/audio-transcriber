# Russian and French transcription accuracy check

Test date: 2026-10-20. This check measures transcript errors against known reference text, not merely whether transcription finishes. All 72 actual CLI invocations finished successfully, but the resulting transcripts are **not error-free**.

## Fixed sample and provenance

- Source: [Google FLEURS](https://huggingface.co/datasets/google/fleurs), official test split, Russian `ru_ru` and French `fr_fr`.
- Pinned dataset revision: `70bb2e84b976b7e960aa89f1c648e09c59f894dd`.
- 12 human-recorded clips per language: 121.68 seconds Russian and 133.02 seconds French. Every model received the exact same 24 files.
- Deterministic selection before inference: SHA-256 of `local-transcriber-accuracy-2026-10-20-v1` + NUL + language config + NUL + filename; take the 12 smallest digests per language. No filtering by length, content, sound quality, or model output.
- All 775 Russian and 676 French test rows were eligible. Selected filenames, row numbers, references, audio hashes, and verified full archive hashes are in `manifest.json`.
- References are supplied with the recordings, not generated by another recognizer or an LLM. Raw and corpus-normalized references agree under the scoring normalization.
- FLEURS is licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribution: Alexis Conneau, Min Ma, Simran Khanuja, Yu Zhang, Vera Axelrod, Siddharth Dalmia, Jason Riesa, Clara Rivera, and Ankur Bapna (2022), [FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech](https://arxiv.org/abs/2205.12446). Reference excerpts here and full paired references in JSON are reproduced under that license.

## Results

Lower WER/CER is better. These are corpus-level micro-averages, not averages of clip percentages. The denominator is 206 normalized Russian words / 1,416 characters and 338 French words / 1,954 characters.

| Model | Language | WER | CER | Word substitutions | Deletions | Insertions | Exact normalized clips |
|---|---|---:|---:|---:|---:|---:|---:|
| small | Russian | 8.25% | 2.26% | 13 | 4 | 0 | 2/12 |
| small | French | 14.20% | 5.68% | 38 | 3 | 7 | 2/12 |
| medium | Russian | 3.88% | 1.34% | 7 | 1 | 0 | 6/12 |
| medium | French | 7.99% | 2.81% | 23 | 2 | 2 | 2/12 |
| turbo | Russian | 1.46% | 0.85% | 2 | 1 | 0 | 9/12 |
| turbo | French | 5.03% | 1.89% | 15 | 1 | 1 | 4/12 |

A 0% clip score means exact agreement after normalization only. Nonzero WER can reflect a real word error, a different word form, or orthographic representation such as digits versus spoken number words. It is not the percentage of recordings that failed, and it does not directly measure semantic correctness.

## How it was tested

- The existing application CLI was copied unchanged and executed for every clip. Its SHA-256 is `d57234cdd27a55a79da2980e2a85e5797c9699d9bf2655f04b1868708de8eade`.
- CPU int8, 4 threads, beam size 5, VAD off, previous-text conditioning off, transcription rather than translation. Known language was supplied explicitly (`ru` or `fr`).
- Models ran one at a time, never concurrently. The model files and their SHA-256 hashes, pinned model revisions, package versions, full hypotheses, and per-clip alignments are in `results/results.json`.
- The application set Hugging Face offline mode and used only previously downloaded local model files during inference. Audio was not submitted to an external transcription service. No private user recording or computer was accessed.
- WER = (word substitutions + deletions + insertions) / reference words. CER uses the same minimum edit-distance calculation over normalized characters, including single spaces between words.
- Normalization: Unicode NFKC and casefold; keep letters, combining marks, and numbers; replace punctuation/symbols with spaces; collapse whitespace. Accents and Cyrillic ё remain distinct. Apostrophes and hyphens become spaces. No spelling correction or number-word conversion is applied.
- Independent verification: jiwer 4.0.0 agrees with every one of the 72 word/character edit totals and all six aggregate WER/CER pairs (tolerance 1e-12). See `results/metric_verification.json`.
- Error-count ties use substitution, then deletion, then insertion. This can change the S/D/I breakdown between equally valid alignments but not total WER/CER.

## Reproduce

Use an environment containing the versions in `results/results.json` (faster-whisper, CTranslate2, PyAV, NumPy, huggingface-hub). The scorer and downloader otherwise use only the Python standard library.

1. Run `python prepare.py`. This downloads approximately 782 MB of public FLEURS test archives to the working directory, verifies their published hashes, and extracts only the 24 chosen clips.
2. Run `python download_models.py /path/to/model-parent`, or provide the exact model revisions listed in `results/results.json` in subdirectories `small`, `medium`, and `turbo`. Include the turbo `preprocessor_config.json`; weights alone are insufficient.
3. Run `python score.py` for the metric unit checks.
4. Move the supplied `results` directory aside first (for example, rename it `results-original`). Then run `python benchmark.py --app /path/to/transcribe.py --models /path/to/model-parent --threads 4`. The benchmark invokes that CLI unchanged and saves each output.
5. Run `python report.py` to rebuild the report and aggregate JSON. A run with an existing `results/per_clip.jsonl` resumes it rather than performing those inferences again.
6. Optionally install `jiwer==4.0.0` and run `python verify_metrics.py` to repeat the independent metric cross-check.

## What this does not prove

- Small deterministic sample, not a full corpus evaluation or statistical proof of one model being best.
- Public official test split, not guaranteed unseen by pretrained Whisper. No model tuning was performed.
- Short human read-speech utterances, not long recordings, dialogue, overlapping speakers, accents, poor microphones or noisy videos.
- Known languages were specified; this does not measure auto-detection accuracy.
- WER/CER assess lexical transcription after the stated normalization, not punctuation, casing, timestamps, or semantic correctness.
- No private user audio was accessed or uploaded. Models ran locally on the assistant cloud VM, sequentially; wall time includes fresh CLI/model loading per clip.
- Corpus references were used as ground truth; the recordings and every word of the corpus annotations were not independently human-audited in this check.
- Long-file completion tests are separate. These short paired clips do not establish word-level accuracy over an entire 30–60 minute recording.
- This small sample is useful evidence that the program transcribes real Russian/French speech and quantifies its mistakes. It is not a guarantee for the user’s recordings or a definitive model ranking.
